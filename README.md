# MANNABRI

Independent iOS app studio from Germany. We build native apps for iPhone with Swift and SwiftUI.

## Apps

- **My Wheelie Tracker**: Track and review your wheelie sessions. [Website](https://mannabri.de/apps/my-wheelie-tracker/en/index.html) · [App Store](https://apps.apple.com/us/app/my-wheelie-tracker/id6781165193)
- **UI Catalog for SwiftUI**: A browsable catalog of SwiftUI UI components. [Website](https://mannabri.de/apps/ui-catalog-for-swiftui/en/index.html) · [App Store](https://apps.apple.com/de/app/ui-catalog-for-swiftui/id6788291355)
- **Farted**: A silly fun app, built because my son asked for it. [Website](https://mannabri.de/apps/farted/en/index.html) · [App Store](https://apps.apple.com/us/app/farted/id6806994447)

More apps are in the works.
