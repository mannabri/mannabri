# Hi, I'm Manuel 👋

I'm the developer behind **MANNABRI**, a small indie studio where I build iOS apps with Swift and SwiftUI. The name is a mix of my first and last name, so every app here comes with a bit of me in it.

I build what I find useful, interesting or just fun, and I ship updates as I learn.

## Apps

- **[My Wheelie Tracker](https://mannabri.de/apps/my-wheelie-tracker/en/index.html)**: Born out of my own wheelie sessions. Track them, review them, get better.
- **[UI Catalog for SwiftUI](https://mannabri.de/apps/ui-catalog-for-swiftui/en/index.html)**: The reference I wished I had while building SwiftUI interfaces.
- **[Farted](https://mannabri.de/apps/farted/en/index.html)**: Yes, really. My son asked for it, so I built it. Worth every giggle.

More apps are on the way.
